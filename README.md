# Ксилофон-рингтон

Android-приложение: загружаете любую песню или мелодию — оно находит в ней главную мелодию
и играет её ксилофоном, как рингтон на iPhone. Готовый рингтон можно прослушать, сохранить
в «Рингтоны» и поставить на звонок.

## Как получить APK

### Способ 1. Без установки программ (через GitHub)

1. Зарегистрируйтесь на github.com и создайте новый репозиторий (кнопка **New**).
2. Распакуйте этот архив и загрузите **всё его содержимое** в репозиторий
   (**Add file → Upload files**, перетащите файлы и папки; папка `.github` обязательна).
3. Откройте вкладку **Actions**. Сборка «Build APK» запустится сама
   (или нажмите **Run workflow**). Она идёт 3–5 минут.
4. Откройте завершённый запуск, внизу в разделе **Artifacts** скачайте `XyloTone-apk`.
   Внутри архива лежит `app-debug.apk`.
5. Скопируйте APK на телефон, откройте его и разрешите установку из неизвестных источников.

### Способ 2. Android Studio

**File → Open** → выберите папку проекта → дождитесь синхронизации →
**Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## Как пользоваться

1. **Выбрать песню** (или «Поделиться» песней из плеера → Ксилофон-рингтон).
2. Выберите длину рингтона. Приложение само найдёт самый яркий фрагмент (обычно припев),
   либо снимите галочку и укажите начало вручную.
3. **Сделать рингтон** — через несколько секунд он начнёт играть.
4. **Сохранить в «Рингтоны»** или **Поставить на звонок** (при первом разе Android попросит
   разрешить приложению менять настройки).

## Как это устроено

Папка `app/src/main/java/com/example/xylotone/engine` — звуковой движок на чистой Java:

- `MelodyExtractor` — ищет мелодию по спектру (устойчиво к аккордам и ударным), режет на ноты,
  подгоняет под ровный ритм и под одну тональность, переносит в регистр ксилофона.
- `XylophoneSynth` — синтез ксилофона: обертоны 1 : 3 : 6, быстрое затухание, щелчок молоточка,
  лёгкая реверберация.
- `RingtoneMaker` — собирает всё вместе. `WavWriter` — запись WAV.

Остальное — Android: `AudioDecoder` (чтение mp3/m4a/ogg/flac…), `RingtoneStore` (сохранение
в «Рингтоны»), `MainActivity` (экран).

Движок можно проверить на компьютере без Android (нужна только Java):

    javac -d out app/src/main/java/com/example/xylotone/engine/*.java tools/EngineTest.java
    java -cp out EngineTest demo.wav

## Ограничения

- Лучше всего работает на песнях с ясной ведущей мелодией (вокал, соло). В плотных аранжировках
  и у речитатива мелодия может получиться приблизительной.
- Рингтон сохраняется как WAV. Требуется Android 10 и новее.
